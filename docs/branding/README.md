# PGOne brand identity

**Product:** PGOne (capital P, G and O; lowercase ne).

**Meaning:** One operating place for PGs, hostels and co-living properties.

**Primary mark:** `pgone-mark.svg` — the navy/royal-blue geometric residence symbol. Use it in launcher icons, splash, header, and docs without redrawing a different house icon.

**Colors:** Ink navy `#0B2148`, royal blue `#2056EF`, white `#FFFFFF`. White/soft grey surfaces should dominate; avoid green, gold, decorative gradients and fabricated claims.

**Mobile wordmark:** `PG` in navy + `One` in royal blue. The visual UI should never display “SafeHouse” as a product name. Technical API domains, callback symbols, Firebase namespace, session keys and the Android package namespace remain unchanged as integration contracts.

**Asset map:** Web logo component: `mobile/frontend/src/components/icons.js`; Android launcher and system splash: `mobile/app/src/main/res/drawable/ic_launcher.xml` and `splash_mark.xml`; startup: `mobile/app/src/main/java/com/safehouse/pg/BrandSplash.java`.

Do not claim official Play Store availability or publish production APK links until a release-signed application and legal/privacy/support setup exist.
